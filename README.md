# pairwise-utility-ai

一群敌人同时冲锋，远程兵挤在墙角不放技能，Boss 在血量一半时突然站着不动：效用评分各维度量纲不同，距离分数直接和血量分数相加，近战永远压过远程；评分曲线在阈值处硬切，敌人走到某个距离突然全部选同一个动作；冷却和资源只作为硬条件，没进入评分，技能可用时所有单位同时抢；目标选择每帧重算，队友之间没有占用声明，十个人追同一个目标；黑板数据异步写入，行为树读到上一帧的位置，敌人朝空地和墙冲锋；打断事件只清当前节点，父节点继续按旧计划执行；AI 更新按固定 30Hz，低帧率时同一 tick 内执行两次技能；Boss 阶段切换用血量百分比，吸血后回到上一阶段又触发一次入场；寻路失败没有降级，单位原地转圈直到超时；群体分散力只考虑邻居，狭窄通道里把队友挤进墙；随机种子按帧号生成，回放时敌人选择不一致；LOD AI 远处只跑低频逻辑，靠近后状态没有补齐，突然卡住；感知系统丢失目标后立即清空仇恨，Boss 走到一半回头。gameplay/utility_ai.py 是核心，tests/test_utility_ai.py 15个红。要修的是：归一化；平滑曲线；冷却入分；目标占用；黑板时效；打断传播；tick 去重；阶段幂等；寻路降级；拥挤避让；确定性随机；LOD 状态补齐；感知丢失。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
